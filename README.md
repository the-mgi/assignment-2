# DS 5007 NLP — Assignment 2: Neural NLP Pipeline (BBC Urdu)

**Muhammad Usama · i25-8007 · DS-A**

Continuation of the Assignment 1 BBC Urdu pipeline: word embeddings (TF-IDF, PPMI, skip-gram
Word2Vec), BiLSTM(-CRF) POS tagging and NER, and a Transformer encoder for topic classification.
Everything is implemented from scratch in PyTorch/NumPy — no pretrained models, no Gensim, no
HuggingFace, and no `nn.Transformer` / `nn.MultiheadAttention` / `nn.TransformerEncoder`
(scikit-learn is used only for the t-SNE projection).

## Layout (mirrors the submission zip)

```
i25-8007_Assignment2_DS-A.ipynb   the notebook: runs every part end to end (all cells executed)
report.pdf                        2-3 page report
embeddings/  tfidf_matrix.npy  ppmi_matrix.npy*  embeddings_w2v.npy  word2idx.json
models/      bilstm_pos.pt  bilstm_ner.pt  transformer_cls.pt
data/        cleaned.txt  raw.txt  Metadata.json          (unmodified Assignment 1 outputs)
             pos_{train,val,test}.conll  ner_{train,val,test}.conll  part2_sentences.json
src/         all implementation code (imported by the notebook)
tests/       unit tests (pytest)
tools/       conlleval.pl (original CoNLL evaluation script)
scripts/     w2v_config_search.py (how the C3 epochs / sub-sampling were chosen)
figures/     every figure of the notebook (PNG)
outputs/     results.json (all reported numbers), w2v_config_search.txt
build_notebook.py, build_report.py, package_submission.py
```

\* `ppmi_matrix.npy` is a dense 10,001 × 10,001 float32 matrix (~400 MB). It is larger than
GitHub's 100 MB file limit, so it is **not** committed (see `.gitignore`); it is included in the
submission zip and is regenerated by running the notebook (Section 1.2). The repository instead
contains the identical matrix in sparse form, `embeddings/ppmi_matrix_sparse.npz` (~5 MB;
`scipy.sparse.load_npz(...).toarray()` gives back exactly the `.npy` array).

### Source modules

| Module | Content |
|---|---|
| `src/a1_preprocess.py` | unmodified Assignment 1 normaliser / tokenizer / lemmatizer / stemmer |
| `src/a1_bridge.py` | re-runs A1 on `raw.txt`, verifies it reproduces `cleaned.txt`, aligns surface ↔ cleaned tokens |
| `src/corpus.py`, `src/topics.py` | loaders, 10k vocabulary, keyword-guided 5-category article labels |
| `src/part1_counts.py` | term-document matrix, TF-IDF, co-occurrence, PPMI, cosine neighbours |
| `src/word2vec.py` | skip-gram with negative sampling (V/U matrices, f^0.75 noise table, BCE loss) |
| `src/embed_eval.py`, `src/eval_sets.py` | analogies (3CosAdd), MRR, t-SNE, fixed evaluation sets |
| `src/pos_lexicon.py`, `src/pos_tagger.py` | rule-based POS tagger built on the A1 lemmatizer/stemmer |
| `src/ner_gazetteer.py`, `src/ner_annotator.py` | seed gazetteer + BIO NER annotator |
| `src/part2_data.py` | 500-sentence dataset, stratified split, CoNLL files |
| `src/seq_models.py`, `src/train_seq.py` | BiLSTM tagger, CRF (forward algorithm + Viterbi), training loop |
| `src/conlleval.py`, `src/metrics.py`, `src/part2_eval.py` | conlleval port, metrics, error analysis |
| `src/transformer.py`, `src/part3.py` | from-scratch Transformer encoder, BiLSTM classifier, training |

## Reproducing

Tested with Python 3.13, PyTorch 2.15 (CPU), NumPy 2.5, matplotlib 3.11 on a 4-core CPU. Urdu
labels in the figures need an Arabic-script font (e.g. *Noto Naskh Arabic*: `apt install fonts-noto-core`)
and matplotlib ≥ 3.10 (which shapes right-to-left text itself).

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt          # CPU PyTorch is enough
```

Run the unit tests (32 tests, ≈ 10 s):

```bash
python -m pytest -q tests
```

Run the whole pipeline — every part, all figures, all saved matrices/models (≈ 55 min on 4 CPU cores):

```bash
jupyter nbconvert --to notebook --execute --inplace --ExecutePreprocessor.timeout=-1 i25-8007_Assignment2_DS-A.ipynb
```

or open the notebook and *Run All*. Per part:

| Part | Notebook section | Main outputs |
|---|---|---|
| 0 | Data, A1 alignment, topic labels | `figures/topic_distribution.png` |
| 1 | 1.1 TF-IDF, 1.2 PPMI + t-SNE, 2.1 skip-gram, 2.2 evaluation + C1–C4 | `embeddings/*`, `figures/tsne_ppmi.png`, `figures/w2v_loss_curve.png` |
| 2 | 3 dataset, 4 BiLSTM, 5 evaluation + ablations | `data/*.conll`, `models/bilstm_*.pt`, `figures/pos_confusion_matrix.png` |
| 3 | 6 dataset, 7 Transformer, 8 evaluation + comparison | `models/transformer_cls.pt`, `figures/attention_article_*.png` |

Other entry points:

```bash
python build_notebook.py                 # regenerate the notebook from its source
python scripts/w2v_config_search.py      # re-run the C3 configuration search (~30 min)
python build_report.py                   # rebuild report.pdf from outputs/results.json
python package_submission.py             # build i25-8007_Assignment2_DS-A.zip
```

All randomness is seeded (seed 42; Part 2/3 comparisons additionally use seeds 7 and 123).
